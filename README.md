## Install

1. Melzo → **Settings → Extensions → Store**, install from `https://github.com/prakha194/Melzo-Extension`
2. **Settings → Playback → audio sources** → drag this extension **above Spotify**

3. **Other fork of myspoti, orpheon, etc also does support this extension**

## Rate it

Vote with 👍 or 👎 on the [Ratings issue](https://github.com/prakha194/Melzo-Extension/issues/1) — Melzo's store shows those reactions as stars. Or tap 👍 in the extension's page inside Melzo's store.

## What it does

- **Playback** — matches the song's title, artist and length against YouTube Music's official catalogue, searching in the song's own language, and streams the AAC/M4A it finds.
- **Downloads** — the same file, saved by Melzo and kept offline.
- **No match, no problem** — a song it can't match plays from Spotify as before.

Permissions: *Play audio from elsewhere* (critical), *Provide downloads* (critical), *Use the internet*. Hosts: `music.youtube.com`, `youtubei.googleapis.com`, `*.googlevideo.com`.
